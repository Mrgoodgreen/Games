# Диагностика проблемы запуска игры

## Вопросы для определения проблемы

Ответьте на следующие вопросы:

### 1. Компиляция
- [ ] Ошибки компиляции? Если да, скопируйте текст ошибки
- [ ] Сборка успешна? (должно быть написано "Build successful")

### 2. Запуск
- [ ] Окно вообще появляется?
- [ ] Если да, то:
  - [ ] Окно полностью черное?
  - [ ] Окно зависает намертво?
  - [ ] Окно закрывается сразу?
  - [ ] Видна какая-то картинка?

### 3. Консоль
- [ ] Открыта ли Output window (Debug ? Windows ? Output)?
- [ ] Видны ли какие-то логи?
- [ ] Если да, скопируйте последние 10-20 строк логов

### 4. Дополнительно
- [ ] Были ли изменения в кодах после последнего успешного запуска?
- [ ] Есть ли файл `Resources/Fonts/Roboto-Regular.ttf`?

## Возможные решения по симптомам

### Окно не появляется вообще
**Возможные причины:**
1. Приложение закрывается при инициализации Application
2. SFML не инициализируется правильно
3. Ошибка в конструкторе Application

**Решение:**
- Проверьте логи в консоли
- Используйте TestMain.cpp для проверки SFML

### Окно черное и зависает
**Возможные причины:**
1. Бесконечный цикл в onEnter() состояния
2. Deadlock в Menu инициализации
3. Рекурсивный вызов функций

**Решение:**
- Добавьте логи в каждый метод
- Проверьте Menu::Init()

### Окно показывает какую-то картинку но игра не отвечает
**Возможные причины:**
1. Проблема с обработкой событий
2. Проблема с DrawGame()
3. UpdateGame() возвращает false

**Решение:**
- Проверьте GetCurrentState() возвращает корректный указатель
- Проверьте Game::stateStack не пуста
