# Snake Game - README

## Описание проекта
Классическая игра "Змейка" с современным интерфейсом, различными уровнями сложности, системой рекордов и звуковым сопровождением. Проект реализован на C++ с использованием библиотеки SFML 2.5.1.

## Требования
- Visual Studio 2022
- SFML 2.5.1
- Windows 10/11

## Управление

### В меню:
- **W / S** - навигация вверх/вниз
- **Enter** - выбор пункта меню
- **B** - возврат назад (в подменю)

### В игре:
- **W** - движение вверх
- **A** - движение влево
- **S** - движение вниз
- **D** - движение вправо
- **P** - пауза

### Ввод имени:
- **A / D** - выбор Yes/No
- **Буквы (латиница)** - ввод имени
- **Backspace** - удаление символа
- **Enter** - подтверждение

## Особенности реализации

### Настраиваемые параметры (GameConfig.h)
- Размер окна: 800x600
- Размер сетки: 30x25 клеток
- Начальная длина змейки: 2 сегмента
- Рост змейки: +1 сегмент за яблоко
- Задержка перед стартом: 2 секунды
- 5 уровней сложности

### Уровни сложности
| Уровень | Скорость (клеток/сек) | Очков за яблоко |
|---------|----------------------|-----------------|
| Simple | 4 | 2 |
| Harder than Simple | 6 | 4 |
| Medium | 8 | 6 |
| Easier than Hard | 10 | 8 |
| Hard | 12 | 10 |

### Файлы данных
- **scores.dat** - бинарный файл с таблицей рекордов (создается автоматически)
