# ?? ARKANOID GAME - Краткий гайд

## ?? Цель игры
Разрушить все кирпичи, используя платформу, чтобы удерживать шар в игре.

### Система очков
- **+10 очков** за каждый разрушенный кирпич
- **Жизни**: начинаете с 3-х жизней
- **Условие победы**: разрушить все кирпичи
- **Условие поражения**: потерять все жизни

## ?? Опции

### Infinite Lives (Бесконечные жизни)
- **ВКЛ**: жизни не заканчиваются
- **ВЫКЛ**: стандартные 3 жизни

### Unlimited Balls (Неограниченные шары)
- **ВКЛ**: можно пускать неограниченное количество шаров
- **ВЫКЛ**: ограниченное количество шаров

## ?? Рекорды

Лучшие 5 результатов сохраняются в таблице рекордов.
Просмотреть их можно в меню: **Records**

## ?? Отладка

### Отладочная информация (F3)
```
PlatformX=400 Ball=(400,400)
```
Показывает координаты платформы и шара для отладки.

### Консоль (Output Window)
Логи инициализации и событий помогают диагностировать проблемы.
Откройте: Debug ? Windows ? Output

## ?? Советы

1. **Используйте мышь** для более точного управления платформой
2. **Ловите шар под углом** для более интересных траекторий
3. **Следите за рекордами** - постарайтесь быть в топ-5!
4. **Используйте опции** для удобной игры

## ?? Визуальные элементы

- **Синий фон** - игровое поле
- **Разноцветные прямоугольники** - кирпичи
- **Синий прямоугольник** - платформа
- **Красный круг** - шар
- **Жёлтый текст** - счёт и жизни
