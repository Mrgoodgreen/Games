# Быстрая диагностика проблем с запуском

## ?? Чек-лист при зависании/ошибках

### Шаг 1: Смотрите консоль
При запуске из Visual Studio консоль должна показать:
```
[Application] Getting instance...
[Application] Constructor: window created
[MainMenuState] Loading font from: Resources/Fonts/Roboto-Regular.ttf
```

**Если консоли нет:**
- Debug ? Windows ? Output
- Или нажмите Ctrl+Alt+O

### Шаг 2: Проверьте путь ресурсов

Где должны быть файлы:
```
C:\Users\roman\Documents\Unreal\xyz-cpp-course-lesson\Resources\
```

Проверьте наличие:
- ? Resources/Fonts/Roboto-Regular.ttf
- ? Resources/Textures/Ball.png
- ? Resources/Textures/Brick.png
- ? Resources/Textures/Platform.png
- ? Resources/Sounds/Hit.wav
- ? Resources/Sounds/GameOver.wav

**Если файлов нет:**
- Логи будут показывать: `Font loaded: NO`
- Это OK, игра работает с fallback цветами

### Шаг 3: Запустите и смотрите логи

| Лог | Значение |
|-----|----------|
| `Font loaded: YES` | Шрифт загружен OK |
| `Font loaded: NO` | Шрифт не найден, используется fallback |
| `Frame: 60, States: 1` | Основной цикл работает |
| Ничего не выводится 5 сек | Зависание при инициализации |

### Шаг 4: Если всё-таки зависает

Добавьте точку останова (breakpoint):
1. Откройте Application.cpp
2. Нажмите на строке `InitGame(game);` слева (F9)
3. Запустите Debug (F5)
4. Пройдите пошагово (F10/F11)

Так вы увидите, где точно зависает.

## ?? Если меню загрузилось

### Управление меню
- **?/? стрелки** или **W/S** ? выбор пункта
- **Enter** ? выбрать
- **Escape** ? вернуться назад

### От меню к игре
1. Select "Start Game"
2. Press Enter
3. Должна загрузиться игра (синяя платформа, красный шар)

### Во время игры
- **Arrow Keys** или **Mouse** ? платформа
- **Space** ? запуск шара
- **F3** ? debug overlay (показывает координаты)
- **Escape** ? меню паузы

## ? Частые ошибки

### "Зависает на полностью чёрном экране"
- **Причина**: Инициализация не завершилась
- **Решение**: Смотрите консоль, проверьте логи
- **Проверка**: В консоли должно быть "onEnter() complete"

### "Меню видно, но текст невидимый"
- **Причина**: Шрифт не загрузился (это OK)
- **Решение**: Скопируйте Resources папку
- **Проверка**: Консоль покажет "Font loaded: NO"

### "Нажимаю Enter, но ничего не происходит"
- **Причина**: Игра зависает при переходе состояния
- **Решение**: Проверьте PlayingState инициализацию
- **Проверка**: В консоли должно быть логи о PlayingState

### "Видна игра, но можно кликать мимо"
- **Причина**: Текущие координаты неправильные
- **Решение**: Нажмите F3 для debug overlay
- **Проверка**: "PlatformX=" показывает координаты

## ??? Отладка через логи

### Включить максимальное логирование
Раскомментируйте в Application.cpp все std::cout.

### Выключить логирование
Закомментируйте все std::cout для чистоты выводов.

### Добавить свой лог
```cpp
std::cout << "[MyState] My message" << std::endl;
```
